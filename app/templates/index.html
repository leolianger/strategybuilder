AI Paper Lab

Upload paper → extract strategy blueprint → save as new strategy

Use your own provider API key. The key is used only for this request and is not saved. To reduce token usage, the app sends a compressed paper excerpt and asks the model for a compact JSON blueprint; Python strategy code is generated locally.

Providers and token efficiency

  • Local extraction keeps only strategy-relevant text.
  • The model returns compact JSON, not full Python code.
  • Strategy Builder creates the Freqtrade code locally.
  • API keys are not stored in metadata or files.
  • Each provider uses its official authentication and response format.

Tip: for scanned PDFs or complex layouts, upload a text/Markdown copy of the paper for better extraction.
